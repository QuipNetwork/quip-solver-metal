## Commands and method

The detached base used `00f568a`, the merge base with this branch. The same `tests/pm1_rates.rs` file ran in each worktree. The runs were sequential. Release test targets compiled before timing. Each result covers eight generated jobs on the 4,577-node, 41,515-edge Advantage2 topology, with 64 reads and 4,096 sweeps per job. The test sorts the eight job times and reports element four as `median_s`. This is the upper middle observation.

```sh
git worktree add --detach ../quip-miner-metal-base 00f568a
cp -f tests/pm1_rates.rs ../quip-miner-metal-base/tests/pm1_rates.rs
cd ../quip-miner-metal-base && cargo test --release --test pm1_rates --no-run
cd ../quip-miner-metal-qui-1642 && cargo test --release --test pm1_rates --no-run
uptime
cd ../quip-miner-metal-base && cargo test --release --test pm1_rates -- --ignored --nocapture
uptime
cd ../quip-miner-metal-qui-1642 && cargo test --release --test pm1_rates -- --ignored --nocapture
uptime
QUIP_PM1_SCALE=wide cargo test --release --test pm1_rates -- --ignored --nocapture
```

## Identical read check

A second ±1 comparison checks every returned read. The test computes a separate 64-bit `FNV-1a` digest for each kernel. It hashes every read in job and read order: the signed energy as eight little-endian bytes, then each signed spin as one byte. These repeat runs used the same two worktrees and only the ±1 path. The wide run did not repeat.

## Wide cost ratio

Wide SA divided by branch int8 SA is `40.0917 / 30.7273 = 1.3048`. Rounded up to one decimal, this sets `WIDE_SA_COST_FACTOR` to `1.4` for chunk sizing. Wide Gibbs divided by branch int8 Gibbs is `0.6429 / 0.3256 = 1.9745`. The same rounding rule sets `WIDE_GIBBS_COST_FACTOR` to `2.0`. These factors use the first measurement set. The planner selects a factor from the wide kernel.

## Wide pipeline limits

Task 5 measured up to 1,024 threads per threadgroup for each wide pipeline: `sa_wide`, `gibbs_wide`, and `gibbs_parallel_wide`. The node-parallel Gibbs group remains fixed at `WIDE_GIBBS_GROUP = 128` for cross-device determinism.

The wide local-field limit and the advertised SA and Gibbs `max_local_field_milli` are `268_435_000`. The value is below `2^28` because quip-solver-core 0.0.3 converts units to milli with `v * 1000.0`. Its exact-step check rejects `268435455.00000003`.

## Multi-spin limit decision

The maintainer kept the advertised multi-spin annealing limit at 16,384 nodes. That limit is the union of the Metal route, which supports 6,016 nodes, and the Apple Neural Engine route, which supports 16,384 nodes.

The maintainer deferred refusal of non-unit models and an exact-coefficients claim for multi-spin annealing until quip-solver-core conformance respects advertised limits. Conformance 0.0.3 sends `J = 0.5` to every binary. Until then, the multi-spin sampler anneals non-unit models by coefficient sign and the host scores the true model.
